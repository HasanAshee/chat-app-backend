# 💬 Real-Time Chat App — Backend

Node.js + Socket.io backend for a real-time chat application with dynamic room creation and message persistence.

🔗 **Frontend Repo:** [chat-app-frontend](https://github.com/HasanAshee/chat-app-frontend)

## ✨ Features
- WebSocket server with Socket.io
- Dynamic room creation on demand
- Message history stored in MongoDB
- RESTful API with NestJS

## 🛠 Tech Stack
NestJS · Socket.io · MongoDB · Mongoose · TypeScript

## 🚀 Getting Started
```bash
npm install
npm run start:dev
```
